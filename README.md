# TX42 test builds

Test builds of **TX42**, the Texas 42 dominoes game, for a small group of testers.

## Install on Android

1. On your phone, open **[the latest build](https://github.com/tylerkeen99/tx42-builds-750573/releases/latest)** and tap the `.apk` file under **Assets** to download it.
2. Open the download. Android may ask you to allow your browser (or Messages, or Gmail) to **install unknown apps**: tap **Settings**, turn it on, then go back and tap **Install**.
3. If **Play Protect** warns that it doesn't recognize the app, tap **More details → Install anyway**. That's normal for a test app that isn't in the Play Store.

## Updates

When a new build is out, TX42 shows **"A new version is available"** on its home screen. Tap it, download the new `.apk` and install it over the old one; your saved game stays.

## Feedback

In TX42, tap **Feedback** on the home screen. It opens an email with your app version and phone model already filled in.

iPhone builds will come through TestFlight later.
